## 2. Mô tả hệ thống
Hệ thống quản lý nhân sự trực tuyến cho phép xem danh sách, thêm mới, tìm kiếm, cập nhật và xóa hồ sơ nhân viên (CRUD).

## 3. Công nghệ sử dụng
- **Frontend:** React (Vite)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Đóng gói & Triển khai:** Docker, Docker Hub, Render

## 4. Hướng dẫn chạy ở môi trường phát triển (Local)
1. Cài đặt thư viện Backend: `cd backend && npm install`
2. Tạo file `.env` trong `backend/` từ `.env.example` và điền `MONGODB_URI`, `PORT=5000`.
3. Chạy Backend: `npm start`
4. Cài đặt và chạy Frontend: `cd frontend && npm install && npm run dev`
